## Hey, I'm Abtahi 👋

I'm a developer and builder from Bangladesh. I love the entire process of making something useful: finding the problem, designing the experience, writing the code, breaking it, fixing it, and finally getting it into people's hands.

My work moves between **production web applications, machine learning, embedded systems, and robotics**. I've worked on everything from an affordable SAT-prep platform and AI-powered farming tools to **lunar mission-control software** and an **interactive 3D underwater robotics website**.

What connects them? **I want technology to help people make better decisions in the real world.**

- 🔭 **Exploring:** decision-making under uncertainty, reliable AI, and intelligent robotics.
- 🛠️ **Building:** full-stack products, practical ML systems, and tools people actually use.
- 🎓 **Sharing:** I've helped teach programming to **900+ students**.
- ⚽ **Away from my desk:** football, drawing, and an unreasonable number of side-project ideas.
